# JSONParse

A fast, ad-free JSON tool that does everything you need — no paywalls, no distractions.

A no-ads, no-sign-up JSON tool. Paste JSON, explore it in tree or graph view, generate types for 9 languages, and format/minify/search — all instantly in the browser.

## Features

- **Tree View** — collapsible, searchable node explorer with path tracking
- **Graph View** — visual relationship map of your JSON structure
- **Raw View** — formatted JSON with key sorting
- **Type Generation** — one-click export to 9 languages/formats
- **Search** — filter keys and values with optional case sensitivity
- **Format / Minify / Sort** — instant JSON transformations
- **Upload & Download** — drag a `.json` file in, download the result out
- **Dark / Light theme** — persistent per-session

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).
